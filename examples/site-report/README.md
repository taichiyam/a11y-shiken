## 再現手順

```bash
# 1. ダミーサイトをローカル配信する（このリポジトリのルートで）
python3 -m http.server 8765 --bind 127.0.0.1 --directory examples/site

# 2. 別のターミナルで検査する
/a11y-shiken examples/site-report/urls.csv
```

URL が `http://127.0.0.1:8765/...` になっているのは、検査対象が同梱のダミーサイトで、
ローカル配信して検査したためである。

## ⚠️ この結果の読み方

- **「axe-core が通ったから確認OK」になった項目は 0 件です。**
  55項目すべてで axe-core の検証範囲は達成基準の一部にとどまるため、axe-core の pass だけを根拠に「確認OK」にはしません（カバレッジガード）。
  上の「確認OK」はすべて Visual / Interactive テスト、または証拠を引用できた生成 AI の判定によるものです。
  判定ソースは各レポートの「担当」列で確認できます。

- **「一部未確認」は「問題なし」ではありません。**
  対応する達成基準の一部に目視確認が必要な項目が残っている状態です。
  一部しか確認できていない項目を「確認OK」に丸めない設計にしています。

- **これは検出精度の実測ではありません。**
  ng 版の正解データ（[ground-truth.md](../site/ground-truth.md)）と突き合わせた精度の測定は、
  正解を伏せた盲検プロトコルで別途行っています（[精度実測レポート](../../docs/accuracy-report.md)）。
  ここに置いているのは **2026-08-21 時点の、上記6ページに対する実行結果そのもの** です。

- **ページ単位の検査です。** ページ間の一貫性を見る達成基準（3.2.3 / 3.2.4 / 3.2.6）は
  1ページの情報だけでは判定できないため「未確認」のまま残ります。
  ng 版はナビゲーションの並び順とラベルを意図的に崩してありますが、この検査では検出されません。

- **正式なアクセシビリティ試験（JIS X 8341-3:2016）の代替にはなりません。**
