ng 版の3ページすべてで検出された問題:

- **2.4.1 ブロックスキップ** — ランドマーク要素（header / nav / main / footer）もスキップリンクも無い（自動判定(Claude)）
- **2.4.7 フォーカスの可視化** — `:focus { outline: none; }` でフォーカスインジケータが消えている（自動判定(Interactive)）
- **4.1.2 名前・役割・値** — 検索の送信ボタンにアクセシブル名がない（axe-core `button-name` / 自動判定(Claude)）
