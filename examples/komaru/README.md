## ⚠️ この結果の読み方

- **「17項目中◯項目を検出できた」といった正解率は出していません。**
  駒瑠市は「システムの都合上、必ずしも障壁の内容と達成基準の番号は一致しません」「開発中でバグが含まれる可能性があります」と明記しています。
  これは **2026-08-18 時点の、上記URLに対する実測結果** です。

- **「一部未確認」は「問題なし」ではありません。**
  対応する達成基準の一部に目視確認が必要な項目が残っている状態です。
  一部しか確認できていない項目を「確認OK」に丸めない設計にしています。

- **正式なアクセシビリティ試験（JIS X 8341-3:2016）の代替にはなりません。**

- 駒瑠市には PDF による情報提供が含まれますが、**本ツールは HTML のみを対象とするため検査していません。**
