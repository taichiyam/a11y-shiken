# WCAG 2.2 Level A + AA チェックリスト

axe-core による自動チェック可否で3カテゴリに分類。

- 🤖 **自動チェック**: axe-core で検出可能。テスト結果をそのまま反映
- 🔄 **部分自動チェック**: axe-core で一部検出可能だが、目視確認も必要
- 👁 **目視確認**: 自動テスト不可。人の判断が必要

---

### 1.4 判別可能

|---------|--------|------------|-------------|
| 1.4.1 色の使用 | A | 👁 目視確認 | 色だけで情報を伝えていないか（例: エラーを赤色のみで表示）。色以外の手がかり（テキスト、アイコン、下線等）があるか |

| 1.4.3 コントラスト（最低限） | AA | 🤖 自動チェック | テキストと背景のコントラスト比が4.5:1以上（大文字テキストは3:1以上）。axe-coreで検出可能 |
| 1.4.4 テキストのサイズ変更 | AA | 👁 目視確認 | テキストを200%まで拡大しても、コンテンツや機能が損なわれないか |
| 1.4.5 文字画像 | AA | 👁 目視確認 | テキストの代わりに画像化された文字を使用していないか（ロゴ等の例外を除く） |
| 1.4.10 リフロー | AA | 👁 目視確認 | 幅320px（400%ズーム）まで縮小しても横スクロールなしでコンテンツが閲覧可能か |
| 1.4.11 非テキストのコントラスト | AA | 🔄 部分自動 | UIコンポーネント（ボタン、入力欄の枠線等）やグラフィックのコントラスト比が3:1以上か。axe-coreで一部検出可能。Visual テストはフォーム部品の境界線のみ検証するため、問題未検出でも pass は出さず warning（アイコン・グラフィックは目視確認） |
| 1.4.12 テキストの間隔 | AA | 👁 目視確認 | 行の高さ1.5倍、段落間隔2倍、文字間隔0.12倍、単語間隔0.16倍に変更しても内容が損なわれないか |
| 1.4.13 ホバー又はフォーカスで表示されるコンテンツ | AA | 👁 目視確認 | ホバー/フォーカスで表示されるコンテンツ（ツールチップ等）が、解除可能・ホバー維持可能・自動非表示しないか |

## 3. 理解可能 (Understandable)

### 3.1 読みやすさ

| 達成基準 | レベル | チェック種別 | 確認ポイント |
|---------|--------|------------|-------------|
| 3.1.1 ページの言語 | A | 🤖 自動チェック | html要素にlang属性が正しく設定されているか。axe-coreで検出可能 |
| 3.1.2 一部分の言語 | AA | 🤖 自動チェック | ページの主言語と異なる言語の部分にlang属性が設定されているか。axe-coreで検出可能 |

### 3.2 予測可能

| 達成基準 | レベル | チェック種別 | 確認ポイント |
|---------|--------|------------|-------------|
| 3.2.1 フォーカス時 | A | 🔄 部分自動 | フォーカスを受け取っただけでコンテキストの変化（ページ遷移、ポップアップ等）が起きないか。Interactive テストがフォーカス前後のURL・DOMスナップショットを比較（遷移は fail、DOM変化は warning、変化なしを確認できた場合のみ pass） |
| 3.2.2 入力時 | A | 🔄 部分自動 | フォーム要素の値を変更しただけで予期しないコンテキストの変化が起きないか。Interactive テストが入力前後のURL・DOMスナップショットを比較（遷移は fail、DOM変化は warning、変化なしを確認できた場合のみ pass） |
| 3.2.3 一貫したナビゲーション | AA | 👁 目視確認 | 複数ページ間でナビゲーションの順序と構成が一貫しているか |
| 3.2.4 一貫した識別性 | AA | 👁 目視確認 | 同じ機能を持つコンポーネントが一貫して識別されているか（同じアイコン、ラベルを使用） |
| 3.2.6 一貫したヘルプ | A | 👁 目視確認 | ヘルプ手段（連絡先、チャットbot等）が複数ページ間で一貫した相対的な位置にあるか |

| 3.3.2 ラベル又は説明 | A | 🔄 部分自動 | フォーム要素にラベルまたは入力説明があるか。label要素の紐付けはaxe-coreで検出可能。説明の適切さは目視確認 |

## 4. 堅牢 (Robust)

### 4.1 互換性

| 達成基準 | レベル | チェック種別 | 確認ポイント |
|---------|--------|------------|-------------|
| 4.1.2 名前（name）、役割（role）及び値（value） | A | 🔄 部分自動 | カスタムUIコンポーネントに適切なrole、name、stateがARIAで設定されているか。axe-coreで一部検出可能 |
| 4.1.3 ステータスメッセージ | AA | 🔄 部分自動 | aria-live領域・role="status"/"alert"/"log"の有無をVisual テストで検出。動的コンテンツ領域へのaria-live未設定もwarningとして検出。属性の存在検査だけでは達成基準を検証できないため pass は出さず常に warning。ステータスメッセージが支援技術に適切に伝わるかはaxe-core + 目視確認 |
