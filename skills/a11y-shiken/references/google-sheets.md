# Google Sheets 連携

`gog` CLI を使って、アクセシビリティテスト結果を既存の Google Sheets スプレッドシートに書き込む機能。

## 前提条件

- `gog` コマンドがインストール済みで認証が通っていること
- 対象スプレッドシートが Google Sheets 形式（xlsx のままでは不可）であること
- **SKILL.md のステップ5.5 が完了し、`{OUTPUT_DIR}/data/{ラベル}/merged-result.json` が生成済みであること**

## 書き込み元は merged-result.json だけ

書き込む内容は `merged-result.json`（55項目の最終判定＝ Single Source of Truth）から**そのまま転記する**。
axe-core の生結果（`axe-result.json` の `passes` / `violations` / `incomplete`）をこのステップで再解釈してはならない。

理由は、最終判定が axe-core の結果だけでは決まらないため。統合スクリプトは axe-core の上に
Claude 判定・Visual / Interactive 検査を重ね、さらに次のガードを適用している（詳細は [how-it-works.md](../../../docs/how-it-works.md)）。

- **カバレッジガード**: `axeCoverage` が `partial` の項目では、`passes` に一致しても「適合」にせず「未確認」に倒す。**現時点で `full` は0件（55項目すべて `partial`）＝ axe-core の pass だけを根拠に「確認OK」になる項目は存在しない**
- **証拠必須ガード**: 証拠（`evidence`）のない Claude 判定は「未確認」へ降格する
- **遷移ルール**: 「適合」への上書きは、上書き元に証拠がある場合のみ通す

したがって「`passes` に一致したから確認OK」という判定をシート書き込み側で行うと、
**本体の Excel / Markdown レポートより緩い結果がスプレッドシートに載る。**
Excel・Markdown・スプレッドシートの3者が必ず一致するよう、判定は必ず `merged-result.json` の値を使う。

## 実行手順

### 1. スプレッドシート情報の取得

URL からスプレッドシートID とシート名を特定:

```bash
gog sheets metadata <spreadsheetId>
```

### 2. 対象シートの確認

対象シートのヘッダーとデータ範囲を確認し、アクセシビリティ項目の行範囲を特定する。
各行がどの達成基準（例: `1.1.1`）に対応するかを読み取り、行番号と達成基準の対応表を作る。

### 3. merged-result.json の読み込みと行の対応付け

`{OUTPUT_DIR}/data/{ラベル}/merged-result.json` を Read ツールで読み込む。`items` 配列の各要素は次の形をとる。

| フィールド | 内容 | 書き込み先 |
|---|---|---|
| `criterion` | 達成基準番号（例: `"1.1.1"`） | 行の対応付けに使う（書き込まない） |
| `displayLabel` | `確認OK` / `修正あり` / `未確認` の3値 | **チェック欄** |
| `source` | `自動判定` / `自動判定(Visual)` / `自動判定(Interactive)` / `自動判定(Claude)` / `要目視確認` | **担当列** |
| `notes` | 判定の根拠・降格理由・「⚠️ 判定矛盾」の経緯 | 備考列（列がある場合） |
| `conflict` | 判定矛盾があった項目は `true` | 備考列の内容で判別できるため、単独では書き込まない |

`criterion` をキーにして手順2で作った行番号と突き合わせ、**値の変換・丸めをせずそのまま**書き込む。
シートの選択肢が `displayLabel` の3値と異なる場合は、対応表をこのファイルに追記したうえで 1:1 の機械的な置換にとどめる
（「未確認」を「確認OK」に寄せる等、判定を緩める方向の変換は行わない）。

`notes` に「⚠️ 判定矛盾」が含まれる項目は、備考列に**要約・削除せずそのまま**転記する。

**複数URLの場合**: `merged-result.json` はラベルごとに1ファイル生成される。書き込み先シートもページ単位で分ける。

### 4. 担当列・チェック欄を一括更新

```bash
gog sheets update <spreadsheetId> '<シート名>!F33:G69' \
  --values-json '[["自動判定","確認OK"],["要目視確認","未確認"],...]'
```

## 注意事項

- スプレッドシートの列構成はプロジェクトにより異なる場合がある。書き込み前に必ずヘッダー行を確認し、担当列・チェック欄の列番号を特定すること
- 手順2で対応付けできない達成基準の行があった場合、推測で埋めずに未書き込みのまま残し、その旨をユーザーに報告する
