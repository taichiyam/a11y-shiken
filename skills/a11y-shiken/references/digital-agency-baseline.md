# 基本17項目（デジタル庁ガイドブック）

出典: デジタル庁『ウェブアクセシビリティ導入ガイドブック』2024-03-29版 §3.1・§3.2
https://www.digital.go.jp/resources/introduction-to-web-accessibility-guidebook

WCAG 2.2 の55項目は、現場で「何から手をつけるか」を判断するには多すぎる。
このガイドブックは、**WCAG のレベルを意識せずに「まずここ」と言える公的なベースライン**を示している。

> **本ツールはデジタル庁・WAIC・W3C・JISC の認証や推奨を受けたものではありません。**
> この集約は、公開されているガイドブックの記述にもとづく参考情報です。

---

## §3.1 重大（非干渉）— 4項目

達成できていないと、**利用者がページの他の部分にもアクセスできなくなる。** リリース前に必ず改修する。

| # | 項目 | WCAG 達成基準 |
|---|---|---|
| 1 | 自動再生はさせない | 1.4.2 音声の制御 |
| 2 | 袋小路に陥らせない | 2.1.2 キーボードトラップなし |
| 3 | 光の点滅は危険 | 2.3.1 3回の閃光又は閾値以下 |
| 4 | 自動でコンテンツを切り替えない | 2.2.2 一時停止、停止、非表示 |

> 3 について、ガイドブックは適合判断の難しさから **2.3.2（AAA）** への適合を推奨している。
> 本ツールの対象は A+AA のため **2.3.1** で判定する。

## §3.2 必須 — 13項目

満たしていないと、内容が十分に伝わらない／操作が不完全にしかできない。

| # | 項目 | WCAG 達成基準 |
|---|---|---|
| 5 | 画像に代替テキストを付与する | 1.1.1 |
| 6 | キーボードだけで全機能にアクセスできる | 2.1.1 / 2.4.3 / 2.4.7 / 3.2.1 / 3.2.2 |
| 7 | 操作に制限時間を設けない | 2.2.1 / 2.2.2 |
| 8 | 単一の表現だけで情報を伝えない | 1.3.1 / 1.3.3 / 1.4.1 |
| 9 | 読み上げ順序が意味の通る順になっている | 1.3.1 / 1.3.2 / 2.4.3 |
| 10 | 見出し要素でセクションを表現する | 1.3.1 / 2.4.6 / 2.4.1 / ~~2.4.10~~ |
| 11 | 文字と背景に十分なコントラスト比 | 1.4.3 |
| 12 | 拡大縮小しても情報が読み取れる | 1.4.4 |
| 13 | 文字・文字コード・フォントの注意 | 3.3.2 / ~~4.1.1~~ / 4.1.2 |
| 14 | ページタイトルを適切に表現する | 2.4.2 |
| 15 | リンクを適切に表現する | 2.4.4 |
| 16 | ナビゲーションに一貫性をもたせる | 3.2.3 |
| 17 | 同じ機能には同じラベルをつける | 3.2.4 |

**判定対象外の達成基準**

| 基準 | 理由 |
|---|---|
| 2.4.10 セクション見出し | **Level AAA** のため A+AA の判定対象外 |
| 4.1.1 構文解析 | **WCAG 2.2 で廃止** |

いずれも「検査できなかった」のではなく「対象範囲の外」である。レポート上も区別して表示する。

## 集約ルール

| 条件 | 状態 |
|---|---|
| 対応する達成基準に1つでも「不適合」がある | ❌ **要修正** |
| 不適合はないが「要確認」「目視確認」が残っている | ⚠️ **一部未確認** |
| 対応する達成基準がすべて「適合」 | ✅ **確認OK** |
| 対応する達成基準がすべて A+AA の範囲外 | — 判定対象外 |

### ⚠️ 絶対に守ること

**一部しか確認できていない項目を「確認OK」に丸めてはならない。**

項目6「キーボードだけで全機能にアクセスできる」は5つの達成基準に対応する。
そのうち3基準が適合でも、2基準が目視未確認なら **⚠️ 一部未確認** と表示する。

ここを丸めると「**間違った合格**」を生む。
間違った合格は、間違った不合格よりはるかに悪い。誰も後から気づかないためである。
